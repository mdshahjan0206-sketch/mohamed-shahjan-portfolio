## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/mdshahjan0206-sketch/mohamed-shahjan-portfolio.git
```

### Navigate to the project

```bash
cd mohamed-shahjan-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
